# ML-Projects

## Spotify Content-Based Recommendation System
### Overview
This project is an Unsupervised Learning application that analyzes 9 different audio features provided by Spotify. The system calculates the mathematical similarity between tracks to provide personalized recommendations.


## Fake Real News Detector
### Overview
This project is a Supervised Learning application that analyzes news articles to identify misinformation and bias.
Unlike the previous recommendation system, this model uses labeled data to learn 
the patterns of "Fake" vs "Real" news through NLP

### Key Features
Text Preprocessing: Automated cleaning of news text.
TF-IDF Vectorization: Converting raw text into numerical features based on word importance.
Classification: Implementing a supervised model to categorize news based on textual patterns and source reliability.
